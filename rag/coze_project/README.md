# 扣子项目「青禾知识库问答助手」的代码副本

线上运行的代码在扣子编程项目里（项目 ID 7702421303852154880），这里存一份与最终部署版本一致的副本，便于查看和评审。只放了本周改动过的文件，平台生成的启动脚本、依赖和存储模块没有复制。

| 文件 | 作用 |
| --- | --- |
| `src/agents/agent.py` | 8 节点工作流：问题改写 → 意图识别 → 知识库检索 → 筛选片段 → 生成答案 → 核对 → 结构化输出 → 记录日志 |
| `config/rag_retrieval.json` | 检索参数：数据集、`top_k=6`、不设相似度阈值、过滤已废止和旧版本段落、列举类上下文 10 段 |
| `config/agent_llm_config.json` | 模型与系统提示词 |
| `scripts/import_kb.py` | 线上知识库导入：启动时按标记判断，文档变化后只补导入改动的段落 |

批量导入 PDF/Word 和检索评测脚本在 `rag/project_scripts/`，问答评测在 `scripts/eval_rag_v2.py`，报告在 `docs/`。
