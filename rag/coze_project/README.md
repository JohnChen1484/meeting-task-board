# 扣子项目「青禾知识库问答助手」的代码副本

线上运行的代码在扣子编程项目里（项目 ID 7702421303852154880）。这里存一份与线上部署版本一致的副本（**w4.3**，2026-11-18），方便查看和评审。只放了改动过的文件；平台生成的启动脚本、依赖和存储模块没有复制。

部署的是哪一版，可以看回答 json 里的 `"version"` 字段，评测报告开头也会列出「作答版本」。

| 文件 | 作用 |
| --- | --- |
| `src/agents/agent.py` | 8 节点工作流：问题改写 → 意图识别 → 知识库检索 → 筛选与重排 → 生成答案 → 核对与压缩 → 结构化输出 → 记录日志 |
| `config/rag_retrieval.json` | 检索参数（数据集、`top_k`、已废止和旧版本过滤、列举类上下文 10 段），以及 `rerank` 段：关键词重排、相对截断 0.8、至少 3 段、同章补全 1 段 |
| `config/kb_chunking.json` | 切片策略配置：A/B/D/S 交给平台按分隔符切；M 为本地语义切片（不依赖分隔符）；O 为扫描件先 OCR 再做语义切片 |
| `config/agent_llm_config.json` | 模型与系统提示词 |
| `scripts/import_kb.py` | 线上知识库导入：启动时按标记判断，文档变化后只补导入改动的段落 |

批量导入、语义切片、OCR、检索评测和重排评测的脚本放在 `rag/project_scripts/`；问答评测是 `scripts/eval_rag_v2.py`，评测集在 `rag/eval/`。第四周的说明见 `docs/知识库问答_第四周优化报告_20261118.md`，各次报告在 `docs/week4/`。
