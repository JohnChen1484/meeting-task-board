# 青禾会议助手 产品手册（v3.2）

## 一、产品简介

青禾会议助手是一款面向企业的智能会议工具，可将会议录音实时转写为文字，自动生成会议纪要并提取待办事项。

## 二、主要功能

1. 实时转写：支持中文、英文、日文三种语言。
2. 智能纪要：会议结束后自动生成会议纪要。
3. 待办提取：自动识别待办事项、负责人和截止日期。
4. 日历集成：支持与企业日历同步会议信息。

## 四、文件上传

支持上传 mp3、m4a、wav、mp4 格式的文件，单个文件不超过 2GB。

## 五、常见问题

**问：购买后可以退款吗？**
答：专业版购买后 7 天内且未使用转写功能的，可申请全额退款。

**问：转写准确率如何？**
答：在普通话、安静环境下，转写准确率约为 95%。
