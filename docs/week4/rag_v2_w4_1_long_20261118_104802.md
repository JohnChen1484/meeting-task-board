### LA2 [宽泛问题、长回答] 公司的信息安全规定主要有哪些？

失败项：必含第 3 组：AI

<pre>**答案**：
1. 数据分级：公司数据分公开、内部、机密、绝密四级，客户数据至少按“机密”级管理（《信息安全与 IT 使用规范》第四条）。
2. 账号与密码要求：系统账号密码长度不少于12位，须同时含大写字母、小写字母、数字、特殊符号，每90天更换一次，不得与最近5次使用的密码相同（《信息安全与 IT 使用规范》第一条）。
3. 设备与网络要求：公司电脑默认禁用U盘等移动存储设备，确需使用须经信息技术部负责人审批（《信息安全与 IT 使用规范》第九条）。
4. 离职与违规处理：员工离职，信息技术部在其最后工作日收回全部系统账号权限（《信息安全与 IT 使用规范》第十二条）。

### LA3 [宽泛问题、长回答] 公司采购有哪些规定？

失败项：必含第 2 组：三家 / 3家

<pre>**答案**：
- 适用范围：适用于公司所有物资、设备、软件及服务的采购（《采购管理规定》第一条）。
- 审批要求：严禁将同一采购事项拆分为多笔以规避审批（《采购管理规定》第二条）。
- 采购电脑、服务器、网络设备及软件许可的，无论金额大小（《采购管理规定》第四条）。
- 按单笔采购金额（或同一供应商同类物品年度累计金额）确定采购方式和审批权限：低于5000元由部门负责人审批后直接采购（《采购管理规定》第三条）。
- 供应商准入须提供营业执照，且近3年内无重大违法记录（《采购管理规定》第五条）。
- 年度采购额超过20万元的供应商，由财务部每年评估一次（《采购管理规定》第六条）。
- 采购物品到货后，由需求部门和行政部共同验收（《采购管理规定》第七条）。
- 验收合格后30个自然日内，由财务部安排付款（《采购管理规定》第八条）。
