问题：新员工入职都要做哪些事？

<pre>1. 入职第一天9:00到对应前台报到，携带身份证原件、学历证书原件、离职证明及一张本人银行卡，领取工牌和笔记本电脑，完成账号开通，与入职伙伴见面（《新员工入职指南》｜一、入职第一天）
2. 入职前3个月由入职满1年的入职伙伴协助熟悉工作与公司文化（《新员工入职指南》｜三、入职伙伴制度）
3. 入职后7天内完成2小时线上信息安全培训，考试需80分及以上，不合格可在3天内补考1次；入职后14天内完成半天线下公司文化与制度培训；入职后30天内完成3小时线上青禾会议助手产品培训并完成课后练习（《新员工入职指南》｜四、必修培训）
4. 试用期3个月，试用期第80天前由直属上级完成转正评估，试用期不参加当季绩效考核（《新员工入职指南》｜二、试用期）

### LA2 · 通过 · 19.6 秒 · 340 字 · w4.3

问题：公司的信息安全规定主要有哪些？

<pre>**答案**：
1. 账号与密码相关：公司系统账号密码长度不少于12位，须同时包含大写字母、小写字母、数字和特殊符号；密码每90天更换一次，不得与最近5次使用过的密码相同；访问公司邮箱和代码库须开启多因素认证（MFA）（《信息安全与 IT 使用规范》第一条）。
2. 数据分级相关：公司数据分为四级：公开、内部、机密、绝密（第四条）。
3. 外部AI工具使用相关：禁止向任何外部AI工具输入机密及以上级别的数据，包括客户数据（第八条）。
4. 设备与网络相关：公司电脑默认禁用U盘等移动存储设备；远程办公访问公司内网须使用公司VPN（第九条）。
5. 离职与违规相关：员工离职的，信息技术部在其最后工作日收回全部系统账号权限；违反本规范造成数据泄露的，视情节轻重给予警告直至解除劳动合同处理（第十二条）。

### LA3 · 通过 · 14.1 秒 · 447 字 · w4.3

问题：公司采购有哪些规定？

<pre>**答案**：
- 适用范围：适用于公司所有物资、设备、软件及服务的采购，严禁将同一采购事项拆分为多笔以规避审批。（《采购管理规定》｜第一章 总则第一条、第二条）
- 采购审批权限：按单笔采购金额（或同一供应商同类物品年度累计金额）划分：低于5000元的由部门负责人审批后可直接采购；5000元及以上、低于50000元的须取得至少三家供应商报价比价并经财务部审核；50000元及以上的须通过公开招标或邀请不少于三家招标确定供应商并经总经理审批；采购电脑、服务器、网络设备及软件许可的，无论金额大小，须事先由信息技术部确认配置。（《采购管理规定》｜第二章 采购审批权限第三条、第四条）
- 供应商管理：供应商准入须提供营业执照且近3年内无重大违法记录；年度采购额超过20万元的供应商，由财务部每年进行一次评估。（《采购管理规定》｜第三章 供应商管理第五条、第六条）
- 验收与付款：采购物品到货后由需求部门和行政部共同验收，验收合格后30个自然日内由财务部安排付款。（《采购管理规定》｜第四章 验收与付款第七条、第八条）
